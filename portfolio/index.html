Features

Everything you need.
Nothing you don't.

A complete hosting administration platform in a single executable — websites, databases, Docker, security, and more.

🌐

Website Management

Create and manage websites with Nginx, Apache, or OpenLiteSpeed. Multi-domain support, URL rewrites, PHP version switching per site.

🗄️

Database Admin

MySQL/MariaDB CRUD with backup & restore, user management, remote access config, and phpMyAdmin integration with auto-HTTPS.

📁

File Manager

Full-featured file browser with Monaco code editor (100+ languages), drag-and-drop upload, compress/decompress, visual chmod, inline terminal.

🐳

Docker Integration

Native Docker Engine API integration. Container lifecycle, image management, real-time logs, per-container stats, volumes & networks.

🔒

Security & Firewall

UFW management, SSH hardening, Fail2ban monitoring, IP blocking, 11-layer middleware stack with CSRF, rate limiting, and audit logging.

📊

Real-Time Monitoring

WebSocket-powered live metrics — CPU, RAM, disk, network at 3-second intervals. Historical data with auto-aggregation. Process manager.

🔐

SSL Certificates

Let's Encrypt auto-issue via ACME, custom certificate upload, self-signed generation, auto-renewal 30 days before expiry.

👥

RBAC Permissions

Three-tier role system — Admin, Operator, Viewer. Tree-based permission editor with 8 categories. Site-scoped multi-tenant isolation.

⚡

App Store

One-click install for Nginx, Apache, PHP (multi-version), MySQL, Redis, phpMyAdmin, OpenLiteSpeed — with real-time progress tracking.

Architecture

Built Different.
Single binary, three tiers.

One Go executable embeds the entire stack — React frontend, REST API, SQLite database, and 21 system services.

⚛️

Presentation Tier

React 19 SPA compiled to static assets and embedded into the Go binary via embed.FS. Served directly by the Go HTTP server — no Nginx required for the panel.

React 19 TypeScript Ant Design 6 Vite 8 Monaco Editor xterm.js
⚙️

Application Tier

Go backend with Gin framework — 18 API handler groups, 21 services, and a 4-worker background task queue. All compiled to native machine code.

Go 1.22+ Gin 1.12 goroutines WebSocket JWT + RBAC gopsutil
💾

Data Tier

SQLite via pure-Go implementation (modernc.org/sqlite) — zero CGO, no external C libraries. 20 tables with automatic schema migrations on startup.

SQLite Pure Go 20 Tables 7 Migrations Zero CGO
🛡️

Security Middleware

11 middleware layers in sequence — from panic recovery to RBAC checks. Defense-in-depth with rate limiting, CSRF, audit logging, and JWT auth.

11 Layers Rate Limiting CSRF Audit Trail TOTP 2FA bcrypt
